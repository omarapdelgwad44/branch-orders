## 1. مقدمة

بصفتك مسؤلاً (Admin)، تمتلك صلاحية كاملة على النظام:

- متابعة **جميع الطلبات** من جميع الفروع.
- اعتماد / معالجة / شحن / إلغاء / إعادة فتح أي طلب.
- إدارة **الفروع** (إضافة، تعديل، تعطيل).
- إدارة **المستخدمين** (إضافة، تعديل كلمة المرور، تعطيل).
- إدارة **الأصناف** (إضافة، تعديل، ترتيب، تعطيل).
- التحكم في **توافر كل صنف** لكل فرع و**أقصى كمية**.
- عرض **التقارير** وتصديرها **CSV**.

> **📷 لقطة شاشة — شعار النظام وصفحة الدخول**
> `docs/screenshots/admin/01-login.png`

## 5. إدارة الطلبات

من القائمة الجانبية → **الطلبات** (أو `#/admin/orders`).

### 5.1 قائمة الطلبات والفلاتر
يمكنك تصفية الطلبات بـ:

- **الحالة** (draft / submitted / approved / processing / sent / received / cancelled ...)
- **الفرع** (اختر فرعاً محدداً)
- **من / إلى** (نطاق تاريخ)
- **بحث نصي** (رقم الطلب، الفرع، أو اسم الصنف)
- **التنقل بين الصفحات** (25 طلب في الصفحة)

> 📷 **لقطة شاشة — قائمة الطلبات مع الفلاتر:**
> `docs/screenshots/admin/05-orders-list.png`

### 5.2 صفحة الطلب (التفاصيل)
اضغط **عرض** بجانب أي طلب لترى:

- رقم الطلب وحالته
- بيانات الطلب (الفرع، تواريخ الإنشاء/الإرسال/الاستلام)
- جدول الأصناف: **المطلوب / المعتمد / المشحون / المستلم / النقص + سبب النقص**
- الملاحظات (ملاحظات الفرع، ملاحظاتك أنت، سبب الإلغاء)
- **الخط الزمني** للطلب
- ملخص الكميات (مطلوب، مشحون، مستلم، نقص)
- زر **طباعة** الطباعة

> 📷 **لقطة شاشة — صفحة تفاصيل الطلب:**
> `docs/screenshots/admin/06-order-detail.png`

### 5.3 التحكم في الطلب (الأزرار الظاهرة حسب الحالة)

| الحالة | الأزرار المتاحة |
|---|---|
| `submitted` | **اعتماد** |
| `approved` | **معالجة** |
| `processing` | **شحن** |
| `received / partially_received / shortage_reported` | **إعادة فتح الاستلام** |
| `draft → sent` | **إلغاء** (مع سبب الإلغاء) |

**الاعتماد:** اضغط **اعتماد** → عدّل الكميات المعتمدة لكل صنف (اختياري) → أضف ملاحظة → **تأكيد**.

> 📷 **لقطة شاشة — نافذة الاعتماد بالكميات:**
> `docs/screenshots/admin/07-approve-modal.png`

**الشحن:** اضغط **شحن** → حدد الكميات المشحونة لكل صنف → **تأكيد**.

> 📷 **لقطة شاشة — نافذة الشحن:**
> `docs/screenshots/admin/08-send-modal.png`

**الإلغاء:** اضغط **إلغاء** → اكتب سبب الإلغاء (إلزامي عملياً) → **تأكيد**. يظهر السبب للمستخدم على صفحة الطلب.

**إعادة فتح الاستلام:** للطلبات المستلمة أو بها نقص — اضغط **إعادة فتح** → يؤكد → يعود الطلب لحالة `sent` لإعادة الاستلام.

> 📷 **لقطة شاشة — تأكيد إعادة الفتح:**
> `docs/screenshots/admin/09-reopen-modal.png`

## 6. حالات الطلب وسير العمل

```
draft → submitted → approved → processing → sent → received
                        │                            │
                        └──── approval bypass ────────┘ (اختياري)
```

- **نقص:** عند الاستلام بنقص مع سبب → `shortage_reported`، بدون سبب → `partially_received`.
- **إلغاء:** في أي مرحلة قبل `received` → `cancelled` (مع سبب).

## 7. إدارة الفروع

من القائمة → **الفروع** (أو `#/admin/branches`).

- **إضافة فرع جديد:** زر **+ فرع جديد** → أدخل اسم الفرع، الموقع، الحالة (نشط/غير نشط). *(رمز الفرع يُولّد تلقائياً).*
- **تعديل فرع:** اضغط أيقونة ✏️ بجانب الفرع → عدّل → **حفظ**.
- **تعطيل فرع:** غيّر الحالة إلى **غير نشط** → عندها لا يستطيع مستخدمو هذا الفرع تسجيل الدخول.

> 📷 **لقطة شاشة — قائمة الفروع + نافذة إضافة/تعديل:**
> `docs/screenshots/admin/10-branches.png`

## 8. إدارة المستخدمين

من القائمة → **المستخدمين** (أو `#/admin/users`).

### 8.1 إضافة مستخدم جديد
1. زر **+ مستخدم جديد**
2. **الاسم الكامل**
3. **اسم المستخدم** (فريد — لا يمكن تكراره)
4. **كلمة المرور** (6 أحرف فأكثر)
5. **الدور:** `فرع` (branch_user) أو `مسؤول` (admin)
6. **الفرع:** اختر الفرع الخاص به
7. **الحالة:** نشط/غير نشط
8. **حفظ**

> 📷 **لقطة شاشة — نافذة إضافة مستخدم:**
> `docs/screenshots/admin/11-user-add.png`

### 8.2 تعديل مستخدم
- **تغيير كلمة المرور:** افتح المستخدم (✏️) → اكتب كلمة مرور جديدة → **حفظ**.
- **تغيير الدور / الفرع / الحالة:** عدّل الحقول المطلوبة → **حفظ**.
- **تعطيل مستخدم:** ضع الحالة **غير نشط** → تُلغى جلساته فوراً ولا يعود قادراً على الدخول.

> 📷 **لقطة شاشة — نافذة تعديل مستخدم:**
> `docs/screenshots/admin/12-user-edit.png`

> ⚠️ **تنبيه:** لا يمكن تعطيل **آخر مسؤول نشط** في النظام (حماية من القفل خارجاً).

## 9. إدارة الأصناف (المنتجات)

من القائمة → **الأصناف** (أو `#/admin/items`).

- **إضافة صنف:** زر **+ صنف جديد** → الاسم، الرمز، **التصنيف** (مثل: مشروبات، منظفات، مستلزمات)، **الوحدة** (كيس، عبوة، كرتونة...)، **الترتيب**، الحالة.
- **تعديل صنف:** أيقونة ✏️ → عدّل → **حفظ**.
- **تعطيل صنف:** الحالة **غير نشط** → يختفي من كتالوج الفروع.

> 📷 **لقطة شاشة — قائمة الأصناف:**
> `docs/screenshots/admin/13-items.png`

## 10. توافر الأصناف لكل فرع

من القائمة → **التوافر** (أو `#/admin/availability`).

1. اختر الفرع من القائمة أعلى الجدول.
2. لكل صنف:
   - **زر التبديل (Switch)** تفعيل / إيقاف توافر الصنف لهذا الفرع.
   - **أقصى كمية** (اختياري): حدّ أقصى يمنع الفرع من طلب أكثر منه.
3. اضغط **حفظ**.

> 💡 **نصيحة:** صنف "غير متوفر" لفرع ما لن يظهر في كتالوج هذا الفرع بالكامل.

> 📷 **لقطة شاشة — صفحة التوافر لفرع معين:**
> `docs/screenshots/admin/14-availability.png`

## 11. التقارير والتصدير

من القائمة → **التقارير** (أو `#/admin/reports`).

| التقرير | ماذا يعرض |
|---|---|
| **الطلبات** | كل الطلبات مع الحالة والتواريخ والكميات والنقص |
| **الفروع** | ملخص أداء كل فرع: عدد الطلبات، مسودات، مقدمة، مشحونة، مستلمة، نقص |
| **الأصناف** | الطلب على كل صنف: مطلوب / معتمد / مشحون / مستلم / نقص |
| **النقص** | كل حالات النقص مع السبب والتاريخ |

**الفلاتر:** الحالة، الفرع، من/إلى، بحث.
**التصدير:** زر **تنزيل** يغطّل ملف `CSV` بالبيانات المعروضة حالياً.

> 📷 **لقطة شاشة — التقارير + زر التصدير:**
> `docs/screenshots/admin/15-reports.png`

## 12. قواعد وأمان مهمة

- **عزل الفروع:** كل مستخدم فرع يرى **طلبات فرعه فقط**. أنت ترى الكل.
- **لا يمكن تعطيل آخر مسؤول نشط.**
- **كلمات المرور** مخزّنة بشكل مشفر (SHA-256 + salt) ولا تظهر في أي قائمة أو تقرير أو ملف CSV.
- **تعطيل المستخدم** يبطل جلساته فوراً.
- **التعطيل للفرع** يمنع دخول مستخدميه حتى يُعاد تفعيله.
